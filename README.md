# Repository Overview
This repository contains a Three.js project that creates a visually stunning and interactive scene. The scene features a variety of elements, including fibers, particles, and a nebula.

## Features
* Interactive scene with fibers, particles, and a nebula
* Customizable theme with three different options
* Adjustable density, pulse, and bloom settings
* Real-time rendering with a high frame rate

## Usage
To use this repository, simply clone it and open the `index.html` file in a web browser. You can then interact with the scene by clicking and dragging on the canvas.

## Customization
The scene can be customized by adjusting the density, pulse, and bloom settings. These settings can be found in the top-left corner of the canvas.

## Themes
The scene comes with three pre-built themes: spectral, inferno, and aether. These themes can be selected by clicking on the corresponding button in the top-left corner of the canvas.
